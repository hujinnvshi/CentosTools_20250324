针对云涌科技飞腾芯片工控机，结合你提供的文件（`autoinstall.conf`/`recovery.scr`/`board.itb`等），下面是**专属的 U 盘启动盘制作+启动操作全流程**（贴合云涌设备特性，优先复用你已有的文件，避免兼容性问题）：

### 一、第一步：明确你已有的文件对应的作用（先理清现有资源）

你提供的文件都是云涌工控机专用的，核心作用如下：
| 你的文件 | 云涌飞腾工控机中的作用 |
|----------|------------------------|
| `recovery.scr` | U-Boot 引导脚本（云涌预定义的启动指令，直接用，无需自己写） |
| `board.itb` | 云涌飞腾设备的**内核+设备树集成镜像**（替代单独的`Image`+`.dtb`，云涌设备专用） |
| `recovery.sh` | 云涌系统部署/恢复脚本（后续启动后执行的核心脚本，替代通用安装脚本） |
| `ISF-3.0.3.1310-f_platform.tar.gz` | 云涌飞腾工控机的**真正系统安装包**（完整 Linux 系统） |
| `autoinstall.conf` | 系统部署的配置参数（告诉`recovery.sh`安装包路径、SN 等） |
| `checksum.txt` | 安装包的 MD5 校验文件（验证系统包完整性） |

### 二、第二步：补充制作启动盘的**必备文件**（你已有大部分，仅需补充 1 个）

仅需额外准备 **aarch64 架构的 BusyBox 二进制包**（云涌飞腾工控机是 64 位 ARM，需对应版本）：

- 下载地址：[BusyBox 官方 aarch64 预编译包](https://busybox.net/downloads/binaries/1.36.0-aarch64/busybox)
- 下载后重命名为`busybox`，确保是可执行文件（后续设置权限）

### 三、第三步：U 盘硬件准备

- U 盘要求：≥8GB（推荐 16GB，Class 10 高速 U 盘，避免写入/启动卡顿）
- 注意：**U 盘会被完全格式化，提前备份 U 盘中的所有数据**

### 四、第四步：在 Linux 环境下制作 U 盘启动盘（核心步骤，分 6 小步）

（推荐用 Ubuntu/CentOS 等 Linux 电脑操作，Windows 兼容性差，易出错）

#### 1. 确认 U 盘设备名（避免误操作本地硬盘！！！）

```bash
# 插入U盘前，先查看当前存储设备
lsblk

# 插入U盘后，再次执行lsblk，找到新增的设备（通常是/dev/sdb，不要选/dev/sda！！！）
lsblk
# 示例：新增设备为/dev/sdb，后续所有操作均基于/dev/sdb
```

#### 2. 给 U 盘分区（云涌飞腾设备适配 MBR 分区表）

执行`fdisk /dev/sdb`进入分区交互界面，按以下步骤输入命令（回车执行）：

```bash
# 1. 清除U盘原有分区表
o
# 2. 创建第1个分区（引导分区，100MB，FAT32格式，存放引导文件）
n
p
1
（直接回车，默认起始扇区）
+100M
# 3. 给第1分区添加“引导标记”（云涌U-Boot识别必备）
a
1
# 4. 创建第2个分区（根分区，占用U盘剩余全部空间，ext4格式，存放BusyBox+你的文件）
n
p
2
（直接回车，默认起始扇区）
（直接回车，默认结束扇区，占用剩余空间）
# 5. 保存分区设置并退出
w
```

#### 3. 格式化 U 盘分区（云涌设备识别要求）

```bash
# 格式化第1分区（引导分区）为FAT32，卷标设为“BOOT”
mkfs.vfat -F 32 /dev/sdb1 -n "BOOT"

# 格式化第2分区（根分区）为ext4，卷标设为“ROOTFS”
mkfs.ext4 /dev/sdb2 -L "ROOTFS"
```

#### 4. 挂载 U 盘分区，部署核心文件

```bash
# 创建挂载点
mkdir -p /mnt/boot /mnt/rootfs

# 挂载引导分区
mount /dev/sdb1 /mnt/boot

# 挂载根分区
mount /dev/sdb2 /mnt/rootfs
```

#### 5. 拷贝文件到 U 盘（分“引导分区”和“根分区”）

##### （1）拷贝**引导文件**到 U 盘的引导分区（/mnt/boot）

（这些是云涌设备启动的核心，用你已有的文件）

```bash
# 拷贝云涌预定义的引导脚本
cp /你的文件路径/recovery.scr /mnt/boot/

# 拷贝云涌飞腾设备的内核+设备树集成镜像
cp /你的文件路径/board.itb /mnt/boot/
```

##### （2）拷贝**BusyBox+你的系统文件**到 U 盘的根分区（/mnt/rootfs）

```bash
# 1. 给根分区创建系统目录（BusyBox运行必备）
cd /mnt/rootfs
mkdir -p bin dev etc proc sys tmp var mnt media
chmod 777 tmp  # 临时目录开放权限

# 2. 拷贝BusyBox到根分区的bin目录
cp /你的BusyBox路径/busybox /mnt/rootfs/bin/
chmod +x /mnt/rootfs/bin/busybox  # 设置可执行权限

# 3. 创建常用命令软链接（方便直接调用，无需加busybox前缀）
cd /mnt/rootfs/bin
for cmd in fdisk tar dd md5sum mount umount sync chmod mkdir rm; do
  ln -s busybox $cmd
done

# 4. 创建设备节点（BusyBox启动必备）
cd /mnt/rootfs/dev
mknod -m 666 null c 1 3
mknod -m 666 console c 5 1

# 5. 拷贝你的系统部署文件到根分区
cp /你的文件路径/recovery.sh /mnt/rootfs/
cp /你的文件路径/autoinstall.conf /mnt/rootfs/
cp /你的文件路径/ISF-3.0.3.1310-f_platform.tar.gz /mnt/rootfs/
cp /你的文件路径/checksum.txt /mnt/rootfs/
```

#### 6. 卸载 U 盘，完成制作

```bash
# 卸载挂载的分区
umount /mnt/boot
umount /mnt/rootfs

# 同步数据（确保所有文件写入U盘，避免损坏）
sync
```

此时，云涌飞腾工控机的 U 盘启动盘已制作完成，可安全拔出 U 盘。

### 五、第五步：云涌飞腾工控机端启动 U 盘并操作硬盘

#### 1. 设置 U 盘为启动优先级

- 将制作好的 U 盘插入云涌工控机的 USB 接口
- 给工控机上电，**快速连续按下`Ctrl+C`或`Space`键**（云涌飞腾工控机的 U-Boot 进入快捷键），进入 U-Boot 命令行界面

#### 2. 在 U-Boot 中启动 U 盘系统

在 U-Boot 命令行输入以下指令（云涌设备适配）：

```bash
# 1. 初始化U盘（云涌设备识别U盘为“usb”）
usb start

# 2. 加载U盘引导分区中的recovery.scr脚本
fatload usb 0:1 0x80000000 recovery.scr

# 3. 执行引导脚本，启动U盘的BusyBox系统
source 0x80000000
```

#### 3. 进入 BusyBox 后操作硬盘（执行系统部署）

工控机启动后会进入`/#`（BusyBox 命令行），此时执行云涌的恢复脚本：

```bash
# 1. 找到U盘根分区中的recovery.sh（通常已自动挂载到/mnt）
cd /mnt

# 2. 设置脚本可执行权限
chmod +x recovery.sh

# 3. 执行脚本，自动部署系统到工控机的内置硬盘（/dev/sda）
./recovery.sh
```

### 六、关键注意事项（云涌设备专属）

1. **U-Boot 快捷键**：若`Ctrl+C`/`Space`无效，参考云涌工控机手册（部分型号是`F2`/`Del`）；
2. **board.itb 不可替换**：这是云涌适配飞腾芯片的集成镜像，不要用通用内核/设备树；
3. **硬盘识别**：云涌工控机的内置硬盘通常是`/dev/sda`，脚本会自动操作，无需修改；
4. **脚本执行结果**：脚本执行完成后会提示“安装完成”，此时重启工控机，拔掉 U 盘，设备会从内置硬盘启动新系统。

按以上步骤操作，即可完成云涌飞腾工控机的 U 盘启动+硬盘系统部署。
